# 📚 EduPro – Predictive Modeling for Course Demand & Revenue Forecasting

> **An end-to-end Machine Learning and Streamlit application that predicts course demand, enrollment, and revenue to enable data-driven decision-making for online learning platforms.**

---

## 📖 Overview

EduPro is a predictive analytics solution designed to help online learning platforms move from **reactive reporting** to **proactive planning**. By leveraging machine learning, the application forecasts future **course enrollments**, **course revenue**, and **category-level revenue**, enabling stakeholders to optimize pricing strategies, launch high-potential courses, allocate instructors efficiently, and maximize business performance.

The project integrates **data preprocessing, feature engineering, predictive modeling, model evaluation, and interactive business intelligence** into a professional multi-page Streamlit dashboard.

---

## 🎯 Problem Statement

Traditional educational planning often depends on historical trends and intuition, making it difficult to anticipate future demand.

EduPro addresses this challenge by providing predictive intelligence that supports decisions related to:

* 📈 Course demand forecasting
* 💰 Revenue prediction
* 🎓 Course launch planning
* 👨‍🏫 Instructor allocation
* 💲 Pricing optimization
* 📊 Category performance analysis

## 🚀 Getting Started

### 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/EduPro_Predictive_Analytics.git
```

### 2️⃣ Navigate to the Project Directory

```bash
cd EduPro_Predictive_Analytics
```

### 3️⃣ Create a Virtual Environment

```bash
python -m venv venv
```

### 4️⃣ Activate the Virtual Environment

**Windows**

```bash
venv\Scripts\activate
```

**Linux / macOS**

```bash
source venv/bin/activate
```

### 5️⃣ Install Dependencies

```bash
pip install -r requirements.txt
```

### 6️⃣ Run the Application

```bash
streamlit run app.py
```
